description: Importa los días nuevos de entrada/temas/, genera el calendario y valida.
---

Usa el agente archivero para procesar los días nuevos de entrada/temas/NN-nombre-del-tema/. Cada día necesita: las imágenes en {ia,real}/ con, junto a cada imagen de ia/, su prompt en español (.txt) y en inglés (.en.txt); tema.es.txt (el tema en español, una línea); y las afirmaciones en facts.en.txt y facts.es.txt (los dos, mismo orden y mismo answer en cada bloque). Si solo hay datos.txt, conviértelo a facts.en.txt y facts.es.txt sin inventar contenido ni tocar datos.txt ni datos.original.txt, y señálame cualquier diferencia de sentido entre las dos versiones. Si falta algún prompt, dímelo: no lo inventes. primero npm run importar -- --simular y enséñame el plan (días, temas, fuentes, recortes de herramientas/lote.json y avisos). Recuérdame que revise a mano que ninguna imagen generada conserve la marca de Gemini. Con mi visto bueno, npm run importar (que también genera data/calendario.json, creditos.html y creditos.es.html) y npm run validar. Para las afirmaciones: npm run afirmaciones -- --simular, enséñame el plan y los avisos de longitud (por idioma), y solo con mi certificación de la lista de revisión de 9 puntos en los dos idiomas, npm run afirmaciones -- --revisado. Para rehacer días ya importados antes del lanzamiento (por ejemplo, tras cambiar recortes, o para pasar un calendario v4 a v5 o data/facts/ v1 a v2) existen npm run importar -- --reimportar y npm run afirmaciones -- --reimportar; con --confirmar el primero borra imágenes de casos/ y el segundo reescribe data/facts/, así que pídeme permiso antes (y --revisado solo si he certificado la lista). $ARGUMENTS

Después, si la validación pasa, haz un commit "datos: nuevo lote de imágenes" con casos/, data/, creditos.html y creditos.es.html (nunca herramientas/banco.json, banco.anterior.json, lote.json ni entrada/, que son solo locales), y dime cuántos días e imágenes entraron y hasta qué fecha llega el calendario. Recuérdame hacer una copia privada de herramientas/banco.json. Si la validación falla, no hagas commit y explícame el problema.
