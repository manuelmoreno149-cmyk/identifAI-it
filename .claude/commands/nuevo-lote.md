---
description: Importa las imágenes nuevas de entrada/, alarga el calendario y valida.
---

Usa el agente archivero para procesar el nuevo lote de imágenes: npm run importar, npm run calendario y npm run validar. $ARGUMENTS

Después, si la validación pasa, haz un commit "datos: nuevo lote de imágenes" con casos/, data/ y CREDITOS.md (nunca herramientas/banco.json, que es solo local), y dime cuántas imágenes entraron y hasta qué fecha llega el calendario. Si la validación falla, no hagas commit y explícame el problema.
